
# 🏏 Cricbuzz LiveStats

## 📌 Project Overview
Cricbuzz LiveStats is a real-time cricket analytics dashboard built using **Python** and **Streamlit**.  
It fetches live cricket match data from an API and displays it in a clean and interactive UI.

---

## 🚀 Features

- 🔴 Real-time live match updates  
- 🏏 Match details (Team names, status, scores)  
- 🎨 Modern card-based UI  
- 🔄 Auto-refresh for live updates  
- 🎯 Filter matches (Live / Completed / All)  

---

## 🛠️ Technologies Used

- Python  
- Streamlit  
- REST API  
- Requests Library
